# Пошаговая инструкция для выполнения задания

## 1. Создание новой ветки

1. Перейдите на страницу своего репозитория на GitHub.
2. Нажмите на выпадающий список веток (по умолчанию `main`).
3. В поле «Find or create a branch…» введите имя ветки, например `feature1`.
4. Нажмите **Create branch: feature1**.

## 2. Редактирование файла README.md

1. В списке файлов кликните на `README.md`.
2. Нажмите иконку карандаша (**Edit this file**).
3. Добавьте не менее 10 строк осмысленного текста.
4. Внизу страницы заполните поле **Commit changes** — кратко опишите изменения (10–100 символов).
5. Нажмите **Commit changes**.

## 3. Создание новых коммитов

1. Повторите редактирование `README.md` или любого другого файла.
2. Придумайте осмысленное сообщение коммита (10–100 символов).
3. Нажмите **Commit changes**.

**Требуется минимум 5 коммитов** в ветке `feature1`.

## 4. Создание Pull Request

1. После создания нужного количества коммитов GitHub предложит **Compare & pull request** — нажмите на эту кнопку.
2. Убедитесь, что источник — `feature1`, цель — `main`.
3. Заполните название и описание PR.
4. Нажмите **Create pull request**.

## 5. Автоматическая проверка

1. После создания Pull Request перейдите на вкладку **Actions** в своём репозитории.
2. Дождитесь завершения workflow **Git Basics Autograding**.
3. Если все проверки пройдены — вы увидите зелёные галочки.
4. Если что-то не так — откройте лог и исправьте замечания, затем сделайте новый коммит.

## 6. Сдача задания

После успешного прохождения всех проверок отправьте преподавателю ссылку на ваш Pull Request.
